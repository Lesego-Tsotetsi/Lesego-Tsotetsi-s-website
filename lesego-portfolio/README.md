# Lesego Tsotetsi Portfolio

A responsive, frontend-only personal portfolio built with HTML, CSS and vanilla JavaScript.

## Folder structure
- `index.html` — page content and sections
- `css/style.css` — responsive styling
- `js/script.js` — mobile menu, active navigation, scroll-to-top and year
- `assets/Lesego_Tsotetsi_CV.pdf` — supplied CV used by the download buttons
- `assets/lesego-profile.jpeg` — profile photograph used in the hero section

## Run locally
1. Extract the ZIP.
2. Open the `lesego-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Confirm that Lesego is happy to publish both phone numbers.
- Add an email address if he wants email contact.
- Replace the training/practice cards with actual projects and links when available.
- Add a profile photograph if desired.
- Keep the CV PDF in the `assets` folder so the download links continue to work.

No backend or database is required.
